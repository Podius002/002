# P002 — Motor de Busca Gamer

Site estático estilo Google com visual **dark gamer / cyberpunk**.

## Características

- Interface inspirada no Google
- Tema escuro com neon (ciano, roxo e verde)
- Partículas animadas + grid
- Busca via Google, DuckDuckGo e Bing
- Modo Proxy (abre sites via serviço público)
- Totalmente responsivo (iPhone + Desktop)
- Pronto para **GitHub Pages**

## Como usar no GitHub Pages

1. Crie um repositório novo no GitHub (ex: `p002` ou `seuusuario.github.io`)
2. Faça upload destes 3 arquivos na raiz:
   - `index.html`
   - `style.css`
   - `script.js`
3. Vá em **Settings → Pages**
4. Em Source escolha **Deploy from a branch** → branch `main` → pasta `/ (root)`
5. Salve e aguarde 1–2 minutos
6. Acesse: `https://seuusuario.github.io/p002` (ou o nome do repo)

## Arquivos

```
P002/
├── index.html   → página principal
├── style.css    → estilos dark gamer
├── script.js    → partículas + busca + proxy
└── README.md
```

## Personalização rápida

- Mudar cores: edite as variáveis em `:root` no `style.css`
- Desativar partículas: clique em “Efeitos” no rodapé
- Trocar engines de busca: altere as opções no HTML

Feito para ser leve, bonito e funcional.
