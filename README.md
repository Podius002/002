## Como atualizar no GitHub

1. Vá no repositório `Podius002/002`
2. Apague os arquivos antigos (ou substitua)
3. Faça upload destes 3 arquivos na **raiz**:
   - `index.html`
   - `style.css`
   - `script.js`
4. Commit

Pronto! O site atualiza em 1-2 minutos.
